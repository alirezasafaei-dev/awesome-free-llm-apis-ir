# انتشار خودکار دامنهٔ اصلی روی Nginx

تنها مقصد فعلی VPS دامنهٔ `https://llm.persiantoolbox.ir/` است. آینهٔ قدیمی بازنشسته شده؛ GitHub Pages نسخهٔ پشتیبان مستقل است. نام تاریخی workflow یعنی `Deploy VPS mirrors` برای سازگاری وضعیت‌های انتشار حفظ شده است.

هر push به `main` آزمون کامل release candidate، بررسی حریم خصوصی، ساخت با SHA دقیق و بسته‌بندی را اجرا می‌کند. انتشار فقط از `main` و محیط محافظت‌شدهٔ `production-global` انجام می‌شود. انتشار دستی Discover هم همین workflow را فراخوانی می‌کند؛ گروه concurrency مشترک جلوی دو انتشار هم‌زمان را می‌گیرد.

Secrets مصرفی محیط فقط `NGINX_SSH_HOST`، `NGINX_SSH_USER`، `NGINX_SSH_PORT`، `NGINX_SSH_PRIVATE_KEY` و `NGINX_SSH_KNOWN_HOSTS` هستند. مقادیر زیرساخت و کلیدها نباید وارد ریپو، لاگ عمومی یا artifact شوند. کلید میزبان باید از اتصال ازقبل‌اعتمادشده تأیید شود؛ بررسی آن نباید خاموش شود.

کلید اختصاصی CI فرمان اجباری دارد و shell، SCP/SFTP، انتقال پورت و اجرای فرمان دلخواه را نمی‌دهد. پروتکل فقط `upload <sha>`، `publish <sha> <sha256>` و `rollback <sha>` را می‌پذیرد. SHA و digest کامل اعتبارسنجی می‌شوند.

helper نصب‌شده توسط اپراتور، مسیر ناامن، لینک، فایل خصوصی، عضو تکراری، حجم بیش‌ازحد، SHA نادرست و تغییر سیاست runtime را رد می‌کند. اسکریپت و unit آپلودشده با root اجرا نمی‌شوند؛ installer، unit و manifest از نسخهٔ root-owned میزبان هستند. تغییر سیاست runtime یا installer نیازمند bootstrap مجدد با بازبینی اپراتور است.

Discover با کاربر محدود خودش اجرا می‌شود. رمز مدیریت در میزبان می‌ماند و هنگام انتشار عوض نمی‌شود. آزمون CRUD با credential محافظت‌شده اجرا و دادهٔ آزمایشی حذف می‌شود. SQLite خارج از release است. فایل‌های استاتیک با اسکریپت atomic موجود منتشر می‌شوند. در شکست بررسی‌ها، اشاره‌گرهای سرویس، runtime و استاتیک قبلی بازیابی می‌شوند؛ rollback قدیمی نمی‌تواند انتشار جدیدتر را برگرداند. Nginx و برنامه‌های PM2 restart نمی‌شوند.

## Bootstrap یک‌باره

پس از تست و بازبینی، سورس تأییدشده را stage کنید و `deploy/nginx/bootstrap-actions.sh` را با مسیر کلید عمومی Ed25519 و نام حساب اختصاصی انتشار اجرا کنید. آن را از artifact آپلودشدهٔ CI اجرا نکنید. کلید خصوصی فقط در فایل محافظت‌شده و GitHub Environment Secret قرار می‌گیرد؛ کلید شخصی اپراتور نباید برای CI استفاده شود.

پیش‌نیازها: دامنه و TLS سالم، Nginx فعال، release فعلی موجود، Discover فعال، credential مدیریت موجود و Linux x64. bootstrap به حساب SSH موجود و سایت‌های دیگر تغییری نمی‌دهد. فایل‌های تشخیص خطا و rollback روی میزبان محافظت می‌شوند.

## تأیید و بازیابی

`npm test` آزمون‌های آرشیو مخرب، پروتکل، مقصد و SHA را اجرا می‌کند. پس از merge، Actions باید واقعاً موفق شود و `build-meta.json` دامنه SHA همان merge را نشان دهد. smoke و UX را با SHA دقیق و سلامت سایت‌های دیگر را جداگانه بررسی کنید. تست محلی به‌تنهایی اثبات انتشار نیست.

برای rollback اخیر، فرمان محدود `rollback <sha>` اجرا می‌شود. نسخهٔ قبلی unit و اشاره‌گرها روی میزبان محافظت می‌شوند. از stop/kill/restart کلی PM2 استفاده نکنید. راهنمای قدیمی دو VPS و Caddy صرفاً سابقهٔ معماری پیشین است و برای میزبان فعلی اجرا نمی‌شود.
