Glossary

Key terms on provider cards

API

The communication channel between your application and an AI model service.

LLM

A large language model for understanding and generating text.

Provider

A company or service that offers API access to AI models.

OpenAI-compatible

The request format resembles the widely-used OpenAI API. Usually usable by changing Base URL and key.

RPM and RPD

Allowed requests per minute and per day. These are capacity limits, not response speed.

Iran status

Network, signup, account activation, and inference are reported separately.

Frequently asked questions

Common questions about free LLM APIs

Do I need to be a developer to use this site?

No — comparing options requires no coding skills. Using an API inside an application requires basic programming knowledge.

What is the difference between a free tier and a trial?

A trial expires after a time or credit limit. A permanent free tier remains usable until the provider changes its policy.

Are all APIs accessible from Iran?

No. Network reachability, signup, account activation, and inference are checked separately for each provider.

What does OpenAI-compatible mean?

The request format is similar to the widely-used OpenAI API. You can usually switch by changing the Base URL and API key.
